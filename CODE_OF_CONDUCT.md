# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Please read the full text there.

In short, we expect everyone taking part in this project to:

- Be respectful and welcoming, whatever their background or experience.
- Give and accept constructive feedback in good faith.
- Focus on what is best for learners and the community.
- Respect privacy. Never post credentials, personal data or private messages.
- Avoid harassment, insults, discriminatory language and trolling.

## Scope

This code of conduct applies in all project spaces: issues, pull requests, discussions and any other community channel for this repository. It also applies when you represent the project in public.

## Reporting

Do not post conduct concerns in public issues or pull requests, and do not use the security vulnerability form — it is for security reports only.

- **About specific content** (a comment, issue, pull request or discussion): use GitHub's **Report content** option from the item's `…` menu. You can choose to report it to the repository maintainers, to GitHub, or both. See [Reporting abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
- **Anything else, or if you need a confidential conversation:** contact a maintainer of the [@Investec-Developer-Community](https://github.com/Investec-Developer-Community) organisation privately (see the organisation's People page), and ask for a private channel before sharing details.
- **If the concern involves a maintainer,** or you are not comfortable contacting one, report it directly to GitHub using [GitHub's report form](https://support.github.com/contact/report-abuse).

Maintainers review reports promptly and treat them confidentially. Enforcement follows section 4 of the Contributor Covenant, from a private warning to a permanent ban from project spaces.
