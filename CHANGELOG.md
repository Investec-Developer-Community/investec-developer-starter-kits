# Changelog

User-visible changes to Launchpad are recorded here. Entries begin with the
current unreleased changes; earlier history is available in GitHub pull requests.

## Unreleased

### Fixed

- Keep checklist edits in memory when browser storage fails, warn that those
  edits are temporary, and offer a retry that merges them with the latest saved
  progress. Retain readable entries from malformed saved data and synchronize
  progress changes and resets between tabs in the same browser.
- Clear outdated Card Guard decisions when purchase inputs or rules change,
  prompt users to simulate again, and expose category-toggle and decision states
  to assistive technology.
- Show field errors for unsupported Interest Maximiser amounts instead of
  crashing the demo.
- Restore library filters when navigating back and forward between history
  entries on the same route, and close mobile navigation on home or route changes.
- Report single-file and CSV download failures with retryable feedback, clean up
  temporary download links and Blob URLs, and keep notification content contained
  on narrow screens.
- Give notification close buttons an accessible name and make them visible on
  mobile and keyboard focus.

### Documentation and tests

- Document the application-owned state machines, transitions, persistence
  boundaries, and recovery behavior in the architecture guide.
- Add regression coverage for storage recovery and cross-tab updates, stale
  decisions, amount validation, history navigation, download failure and retry,
  keyboard notification dismissal, and accessible failure states.
- Verify starter ZIP filenames and exact generated bytes behaviorally, and
  distinguish fully clipped screen-reader announcements from visible overflow
  without weakening the visible-content checks.
